Para exportar tudo o que a placa precisa, use vcd file placa.vcd seguido de vcd add -r /fp_adder_demo_tb/* antes do run -all. Exportar só a janela de waveform deixa de fora os HEX0–HEX5 de 8 bits, que são os que carregam o ponto decimal. Segmentos em âmbar significam X, U ou Z — indefinido, não apagado. O valor decimal é lido dos próprios displays: HEX2 como expoente, HEX1:HEX0 como fração, HEX3 como sinal e o C do HEX5 somando 16 ao expoente. Desmarque a opção do layout se o VCD for de uma versão anterior, em que o sinal vinha no ponto decimal do HEX2.
